How approvals work

Enter or inspect a candidate path only when it points to a card image already in CardVector's Cloudflare R2 archive. Use Preview before approving. You can mark a card for later review, reject an incorrect candidate, or keep it missing. These records are kept in a separate private review table; no automatic live-image replacement occurs. For entire missing sets, use external sources to research artwork and licensing rather than approving cards without verifying identity and finish.
